### Específico desta release

Duas mudanças desta versão pedem atenção extra, porque nenhuma delas foi vista rodando:

| # | Verificação | Resultado | Data |
| --- | --- | --- | --- |
| 13 | **Tela de recuperação por schema incompatível.** Aponte um perfil descartável para um banco com schema acima do `LATEST_SCHEMA_VERSION` e rode `npm run desktop:qualification`. A tela precisa aparecer, mostrar os dois números e oferecer as duas saídas. | | |
| 14 | **Arte de fundo do tema claro.** Ela mudou de "nebulosa escura clareada" para arte própria, e ninguém a viu ainda. | | |

O item 13 é o mais importante da release: é a tela que a pessoa vê justamente quando acha
que perdeu o livro.
