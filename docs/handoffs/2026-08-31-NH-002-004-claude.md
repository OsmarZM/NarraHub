## O que foi feito

- **NH-002** — `npm run release:validate-version` passou a rodar no job `frontend` do
  `.github/workflows/ci.yml`, antes do build. Antes só existia na pipeline de release.
- **NH-003** — `scripts/validate-release-version.mjs` passou a exigir que o cabeçalho
  `## Versão X.Y.Z` do README e a entrada mais recente do CHANGELOG batam com os
  manifests. Mensagens de erro agora nomeiam o arquivo divergente.
- **NH-004** — README e `docs/ARCHITECTURE.md` reescritos para o estado corrente.

## Decisões

Nenhuma decisão arquitetural — nenhum ADR foi necessário.

Duas decisões locais que valem registro:

1. O validador exige o cabeçalho `## Versão X.Y.Z` no README como formato. Se alguém
   mudar o título dessa seção, o CI reprova com uma mensagem explicando o que falta.
2. O CHANGELOG só tem a **entrada mais recente** validada, não o histórico inteiro. O
   objetivo é impedir release sem nota de mudança, não congelar o passado.

## Descobertas importantes

- **O validador já existia e já cobria os três manifests.** A NH-002 não era escrever um
  script, era plugar um script existente no CI. O plano original supunha trabalho novo
  aqui — não era.
- **Por isso os três manifests nunca divergiram entre si**, e ainda assim o README ficou
  três releases atrás: o que faltava não era rigor, era cobertura. Vale como princípio
  para as próximas fases — um gate que não cobre o arquivo errado dá a falsa sensação de
  estar protegido.
- **`src-tauri/src/commands/` (legado) tem 9 arquivos de comando** convivendo com
  `interface/tauri/` (9 arquivos). São dois caminhos completos até o banco, não uma sobra
  pequena. A Fase 3 é maior do que "remover uma pasta".
- **A alegação de que não há SQL no frontend foi verificada, não aceita.**
  `tests/frontend-boundaries.test.mjs` varre `src/app/` inteiro e reprova qualquer SQL; a
  capability `sql:allow-execute` foi removida; `DatabaseService` sobrou só para o ciclo de
  vida do pool, com teste garantindo que ele não expõe `execute`/`select`.
- A árvore de trabalho tem modificações **alheias** não commitadas em
  `src-tauri/Cargo.toml` (perfil `[profile.dev]`), `src/index.html`, `src/styles.css` e
  assets novos em `public/`. Não foram tocadas.
